1 · Which number weight, at which size

Each cell: how alike the look-alike digit pairs (3/8 6/8 8/9 5/6 1/7 0/8 3/5) look on average from 2.25 m, at that size and weight — lower is better; best in each row outlined. stroke = thickness of the "1" stem from 2.25 m. Thin strokes lose contrast first as size falls; very heavy ones fill the gaps in 3, 5, 6, 8 and 9. The column for the current number weight is shaded.

2 · The type scale, measured on Outfit

measured on = what the eye uses for that role: digit height for numbers, capital height for UPPERCASE labels, x-height for mixed-case words · at 2.25 m = that height in arcminutes (ISO 9241-303: 16′ minimum, 20′+ comfortable) · readable from = the furthest distance at which it still reaches 16′. Sofa tier must reach 2.25 m comfortably; the recognise tier is learned shapes (you know it says JEFFREY); walk-closer is for standing at the screen. Sizes are editable.
